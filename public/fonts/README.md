# Self-hosted fonts

Inter and Space Grotesk were downloaded from Google Fonts CSS; Material Symbols Outlined from the Google Fonts symbols stylesheet. The CSS preserves font declarations and character subsets, replacing external font URLs with local paths. Browsers make no Google font requests.

- Inter: SIL Open Font License (`Inter-OFL.txt`), https://github.com/google/fonts/tree/main/ofl/inter
- Space Grotesk: SIL Open Font License (`SpaceGrotesk-OFL.txt`), https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Material Symbols: Apache License 2.0 (`MaterialSymbols-LICENSE.txt`), https://github.com/google/material-design-icons

Files are named using the first 16 hexadecimal characters of the source URL's SHA-256 hash. Keep these license notices with redistributions.
